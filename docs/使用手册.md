# Agent Vocal Studio

本地 Rust 歌声与多轨编排编辑器。用户在桌面编辑，外部智能体通过 MCP 操作同一工程。模型、对话和 API 密钥由外部客户端管理。桌面命令面板的「关于」显示当前运行的版本。

## 启动

双击 `启动歌声编辑器.vbs` 或 `bin/agent-vocal-desktop.exe` 打开独立 Windows 窗口。界面使用系统 WebView2 Runtime，在应用内加载私有资源。编辑器与音频渲染使用本机服务，无需在线音乐生成订阅。

重开时恢复上次在窗口里打开的工程。Agent 在后台保存、创建或渲染其他工程时，当前窗口保持原有工程。已有窗口关闭后，也可用 `bin/agent-vocal-desktop.exe --project <工程ID>` 直接打开指定工程。

启动时优先加载指定或上次打开的工程，侧栏工程列表同时刷新。工作区会保存已校验的摘要，重启后继续复用。工程文件或引用的音频发生变化时，对应条目会重新校验。

点顶部「工具」或按 Ctrl+K 搜索编排、音频片段、歌声、混音和 Agent 命令。播放时，编排和钢琴卷帘随游标横向翻页。手动滚动时暂缓跟随，需要持续查看其他位置时可关闭播放栏的「跟随播放游标」。

顶部文件夹打开工程列表，可搜索名称或工程 ID，每页显示 40 项。「测试」用于查找在工程设计中明确标为技术测试的工程。关闭列表时，保存和播放可继续工作。

`Ctrl+K` 搜索命令，`F1` 查看快捷键，`Ctrl+O` 导入工程或伴奏，`Ctrl+Shift+S` 另存工程包。

可单独安装 VOICEVOX 0.26.2。首次在另一目录安装时，运行 `安装本地歌声引擎.ps1`；它从官方发行地址下载、校验 SHA-256，再用 Windows tar 解压。软件源码包不捆绑音源、编译工具链或用户歌曲。

也可安装 OpenUtau WORLDLINE-R 适配器，通过本机日语 Classic 声库试听和渲染。 [安装、声库配置与使用说明](../adapters/openutau/README.md)

## 已实现

- 自绘标题栏、拖动手柄、窗口按钮、命令面板与文件选择器，普通窗口带投影。内置 Inter 和 Noto Sans SC 字体，使用近黑工作区。
- 阶跃变速、渐变速度、变拍号，支持播放跳转与选区循环。
- 渲染完成的双声道混音由 Rust 通过 Windows WASAPI 播放。停止、定位和选区循环使用同一源帧时钟，播放栏显示左右峰值电平。
- 所有轨道常驻上方编排。下方根据选择显示钢琴卷帘、音频波形或批量属性。拖中间分隔条可调整高度，`F2` 收起或恢复下方编辑器。
- 编排工具栏的旗标按钮可编辑段落名称和起止拍。点击拍尺上的段落可定位并选中该段所有轨道，双击可编辑。标记随工程和 AVPACK 保存，可一次撤销。
- MIDI 导出把段落名称和起点写入标准 Marker 事件。导入时，下一条标记或文件末尾用作本段终点。文件停在最后一条标记上时，末段延到下一小节线。需要精确保留段间空白、末拍和段落职责时，用 AVPROJ 或 AVPACK。
- 框选多个音频片段后，下方按轨叠放波形，并用同一拍尺显示起点、空隙、对拍点和淡化。点击波形定位，聚焦波形后可用左右键按当前网格移动游标。定位保留选区，框内片段仍可一起调整增益。
- 按 `Shift+S` 或点击「切分」可预览切点。A/B 默认听切点前 0.3 秒和后 0.5 秒，按工程边界截取。可应用已试听的草稿，或关掉面板继续编辑。
- 拖动轨头右下角的三横线可重排音轨，也可用 `Alt+↑`、`Alt+↓` 移动当前轨。编排和混音器共用顺序，拖动时出现插入线，松手后一次保存。轨色随原音轨移动，重排可撤销。
- 将鼠标移到轨头，点击复制图标，或按 `Ctrl+Shift+D` 复制当前轨。副本紧跟原轨，默认静音，包含曲谱、调声、音频片段和混音设置。可单独编辑，一步撤销。
- 一轨可放多个音频片段。拖动可以换位置或音频轨，拖边缘可裁剪。多选后按 `S`，游标穿过的片段在同一拍切开，一步撤销。切点要避开淡化区。`L` 可循环所选片段。MCP 用 `audio_clip_group` 的 `{kind:"split",at:拍位}` 预览并提交，传入的每个片段都须跨过该切点。
- 选中一条或多条音频片段后，点「滑移」或按 `Alt+S`。输入源音频读取偏移，预览后可 A/B 试听，再一次应用或撤销。片段位置、长度、淡化和对拍坐标固定。MCP 用 `audio_clip_group` 的 `{kind:"slip",source_delta_frames:480}` 将每个片段的读取点移到源音频晚 10 ms 的位置。源音频余量不足时整组拒绝。 [Logic Pro 用户手册中的 Slip 编辑](https://support.apple.com/en-ie/guide/logicpro/lgcpf7c0d489/mac)
- 向外拖片段边缘可拉回裁掉的源音频。跟速片段沿边缘原有比例延长，已保留的对拍点继续落在原拍位。延长边保留原淡化长度。需要叠放时可按住 `Alt` 拖动边缘。MCP 用 `audio_waveform` 的 `asset_frames` 查看源音频总帧数，用 `audio_clip_edit` 的 `trim` 预览。起止帧都以当前片段源音频起点为零，`first` 可为负，`end` 可超过当前长度。接口先验证素材余量、工程起点和叠放，再接受同一预览的提交。
- 钢琴卷帘、歌词、力度、音高曲线、颤音、中文音轨。
- 给紧接在前一个音符后面的歌声音符勾选「延续上一字」，可让同一个元音跨音高连续演唱。每个音符保留自己的音高、时值、力度、滑音与颤音。起始读音需为一个带元音的假名音拍。「延续上一字」和调声保存在 AVPACK 中，MIDI 保留音符和领音的歌词。 [VOICEVOX 歌声帧接口](https://github.com/VOICEVOX/voicevox_engine#http-リクエストで歌声合成するサンプルコード)
- 框选、多选、移调、量化、复制、乐句移动、时值调整及撤销重做。
- 在编排区框选多轨后可同时移调歌声和有音高的乐器。直接按 ↑、↓ 预填一个半音，按 Shift＋↑、Shift＋↓ 预填一个八度。面板预览每轨音域，可以试听 A/B，再一次应用。
- 编排区框选多轨后按 Q 打开量化。支持直拍和三连音网格、量化强度及摇摆，预览显示各轨最大起音移动量，可先试听 A/B。降低强度可以保留部分原演奏的时间偏差。 [Ableton Live 量化工具手册](https://www.ableton.com/en/live-manual/12/midi-tools/#1127-quantize)
- Agent 按音轨/时间/音高/编号选区，先预览再原子提交；也可读取人框选的范围。
- 提供 MCP 接口与 CLI。Agent 用发光描边的圆角三角指向正在处理的位置，活动栏显示实际操作、阶段和结果。只有桌面能上报用户选区，外部智能体通过 `from_ui:true` 读取。
- `F3` 打开效果器。播放当前版本后，可边听边调整轨道均衡、压缩、延迟与混响。播放游标与循环保持运行。效果进入导出的混音和对齐分轨。
- 「齿音控制」是分频效果器。高频检波超过阈值时才衰减高频段，最大衰减限制处理深度。Agent 可从 `effect_catalog` 读取 `de_esser` 的默认值，并在 `render_status.result.track_effects` 核对 `de_esser_max_reduction_db`。 [分频与齿音阈值](https://www.fabfilter.com/help/pro-ds/using/advancedcontrols)
- `F5` 打开多轨混音器，编排区仍可见。每轨有电平、声像、静音、独奏和插入后立体声电平表。拖动时试听草稿，松手保存一次，按 Esc 还原。
- 混音器的「路由」可设置编组和共享混响、延迟。勾选多轨可将其主输出交给同一个编组，点击编组或返回通道的名称可打开其插入链。已存在的通道可以边播放边调节，新增或移除编组或返回通道后，从编辑器重新播放。
- 作品设计、9 类知识主题、14 类风格指南与观察性曲谱复核。
- 「曲谱复核」可定位首字、长音、最高音和句尾，并显示附近的伴奏入音。点听点回到对应音符，点旁边的播放图标即可对照该处的全混和人声轨。句尾试听带上收尾和后续伴奏。
- 本地 Rust 采样器：钢琴/吉他/贝斯/弦乐/鼓组等，128 个 GM 主音色与 287 个实际预置；乐器轨支持和弦、力度、踏板和表情控制。
- WAV、MP3、FLAC 伴奏导入、波形、48 kHz 重采样、歌声混音与对齐分轨。
- 「导出音频」使用当前版本已完成的渲染，可选立体声混音或一条分轨，支持 44.1／48 kHz 和 16／24 bit PCM WAV。48 kHz／24 bit 保持原文件。MCP 用 `project_export` 的 `format:"wav"`，传 `mix_job_id` 和 `expected_revision`，可选 `stem`（渲染回执的文件名）、`sample_rate` 和 `bit_depth`。
- 选「全部分轨 · ZIP」可一次保存渲染里的直出轨、编组和返回。ZIP 附有分轨清单、对齐帧数和音源署名信息。MCP 用 `format:"wav_stems"` 和同样的格式参数，收到任务 ID 后用 `render_status` 查看进度和结果，用 `render_cancel` 停止打包。
- 在编排区框选后，导出音频的「时间范围」可切换到框选。每个文件从选区起点开始，选区终点后的声音留在完整渲染中。MCP 可传 `beat_range:[起拍,止拍]` 或 `arrangement_query` 返回的 `box_id`。框选决定导出的时间，输出内容由混音、分轨或 ZIP 选项决定。回执和 ZIP 清单用 `source_frame_range` 记录原始 48 kHz 位置。
- 在「导入」选 Studio 分轨 ZIP，可把每个 WAV 一次加入当前工程的新音频轨。选区包沿用清单里的起拍，整首包放在第 0 拍。全部分轨共用起点，可一次撤销。MCP 用 `audio_import` 和 ZIP 的绝对路径，可传 `start` 覆盖起点，也可先用 `dry_run:true` 读取分轨和 `source_sha256`，提交时用 `expected_source_sha256` 绑定同一个包。
- 原生 JSON 工程、带素材的 avpack 工程包、MIDI 导入导出与 NT/NT2 PPSF 导入预览。
- 渲染阶段进度、安全取消、刷新后重连和重启后任务回执；完整音频才发布到导出目录。
- 服务启动后在后台索引已有的渲染回执。试听按工程、版本和歌声引擎找混音，改谱后的版本可以直接判断是否需要渲染。实时进度从正在运行的任务读取，中间回执合并写入。
- 重新打开工程时可复用同一工程版本和音源已完成的混音。混音参数变动也会复用匹配的原始轨，修改曲谱时重新生成受影响的音源。播放游标独立更新，卷帘和编排只在内容、选择或视口变化时重绘。
- 改尾音或段落导致工程时长变化时，只要缓存仍覆盖所需时长，全混试听和导出都会复用未修改轨的原始采样。保存的采样最多预留 1 秒余量，导出仍按工程时长。效果链、路由和总线随草稿重新计算。
- 原子保存、版本冲突保护、备份恢复；深色平面 UI、SVG 图标、统一进退场动效和减少动态效果设置。

要安装乐器音源，请运行 `安装乐器音源.ps1`。采样器为 RustySynth，采样库为 GeneralUser GS 2.0.3，保留原许可与 SHA-256 校验。

## Agent 使用

按[仓库首页的 MCP 指南](../README.md#mcp-接入)注册 `agent_vocal_studio`。新会话加载配置后即可使用。

`--home` 可以指向独立的可写工作区。同一工作区的桌面和 MCP 共享服务，分别启动的工作区各用自己的回环地址和工程目录。

用 `project_list` 的 `scope:"workspace"` 查找作品。选填 `query`、`limit`（1–200）与 `offset`（从 0 开始），结果按最近修改排序。技术验证用 `scope:"technical"`，无参数仍返回全部工程。按结果的 `id` 调用 `project_read`。

新歌先读取 `music_knowledge` 的 `pop_production`、所需风格与 `instrument_catalog`。用 `composition_design` 保存设计，或通过 `project_edit` 的 `set_project.values.composition` 随同主唱和简伴奏一起提交。给 `add_track` 传 `track_ref:"keys"`，即可在同批次的 `add_notes` 中用 `track_ref:"keys"` 写入新轨。批次保存时返回持久音轨 ID。后续编辑用实际 ID。详见 [流行歌制作与返修](流行歌制作与返修.md)。

指定修改：`project_read` → `selection_resolve` → `agent_focus` → `selection_edit` 默认预览 → 核对影响范围 → 同版本提交 → 读回。

将 `agent_focus` 返回的 `intent_id` 传给同版本的 `project_edit`、`selection_edit` 或 `render_start`，可在状态栏同时看到 Agent 要做的具体任务和执行结果。选区预览可以把同一 ID 传给正式提交。工程更新后，先读取新版本，再为下一项操作申报目标。

调整轨道顺序时，用 `agent_focus` 的 `region:"arrangement"` 和 `track_id` 指向轨头。随后在 `project_edit` 发送 `move_track`，`before_track_id` 为插入位置下一轨的 ID，放到末尾时传 `null`。

在 `project_edit` 中用 `duplicate_track` 和 `track_id` 复制一条音轨。可指定 `name`。如果在同批次继续修改副本，为复制操作填写 `new_track_ref`，后续操作使用相同值作为 `track_ref`。音符和片段有独立 ID，音频素材共用。

`composition_review` 返回每句的 `listening_points`。同一个音符承担多个角色时合并显示。每点按当前速度曲线计算前后半秒内最近的谱面伴奏入音。附带的 `audition_range` 取听点前 550 毫秒及后 750 毫秒，按复核拍范围和渲染长度截取。已有该版混音时，可直接把这段传给 `range_audition`，在同一采样区间听全混和人声。

渲染返回 `job_id` 后用 `render_status` 跟踪；连接中断先用 `render_jobs` 找回任务。`render_cancel` 请求停止，但歌声引擎当前请求需要先返回；收到 cancelled 才算停止。

人已经框选时，`selection_resolve` 使用 `from_ui: true`。不要把音符数组下标当成持久身份；不要在冲突后盲目重试。

选择同一歌声轨的音符，打开「歌词」即可整句落字。连续假名可以直接预览，包含汉字时用「提取日语读音」得到本地 VOICEVOX 的建议并手动核对。拗音合在一个音符，促音和延长的元音各占一个音符。确认数量与位置后应用，时值、音高、颤音与选区外音符保持原样。Agent 可用 `lyrics_reading` 和 `selection_edit` 的 `align_lyrics` 预览并应用。兼容模式「空格分隔的逐音输入」保留手工逐音编辑。

在「原歌词」填入原文，再预览并应用。原文会和完整乐句的音符一起保存，在「曲谱复核」里可读原词并定位。横移完整乐句沿用绑定，编排区复制完整乐句时生成一份新的绑定。之后改动读音、错开音符或删除音符时，复核会保留原文并标出待核对状态。拖腔按同一个字的完整音符绑定。 [MusicXML 歌词与延音标记](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/lyric/)

Agent 可在 `fit_lyrics`、`align_lyrics` 或 `set_lyrics` 中传 `written_text`，与读音一次确认。也可用 `project_edit` 的 `set_lyric_line` 写入已有乐句的原词，指定 `track_id`、完整 `note_ids` 和 `text`。用 `composition_review.score_detail.lyric_lines` 核对原文和实际落字，原词绑定保存在原生工程及 AVPACK。

多轨复制、移动和清除的预览会列出各轨原词变更。MCP 在 `tracks[].lyric_changes` 返回原词绑定、受影响的音符数及变更后的对齐状态。完整选中的乐句提供原词及首尾拍，局部框选提供范围内的变更计数。用同一个预览 ID 准备 A/B，即可试听并应用该版本。

编排区框选后，用 `arrangement_query` 的 `from_ui:true` 读取并固定当前框选。返回的 `box_id` 对应工程版本、拍范围、音轨及实际选中的音符和片段。清单保留框内的空轨，并标出跨边界的音符、延音和音频片段。把 `box_id` 带入 `arrangement_edit` 的预览和应用，或带入 `arrangement_audition` 的 `prepare`。复制和移动的目标仍由请求显式给出。重新框选可以建立新回执，已固定的框选继续指向原范围，工程版本变化后需重新读取。

音符多于读音时，选「按旋律延音」。预览列出读音从哪一拍开始、覆盖几个音符，持续的元音会标记「〜」。拖腔只能跨相触的音符，休止处重新落字。选区里已有拖腔时，请一起选中该读音的起始音符和后续延音。读音改变时，预览会标出将恢复自动的子音和元音微调。确认后应用，一步即可撤销。MCP 可用 `selection_edit` 的 `fit_lyrics`，可选 `anchors:[{mora_index:1,note_id}]` 把指定读音固定在指定音符上。

选中同一歌声轨里首尾相接的两个音符，点「滑音」可按毫秒调整边界前后的滑音，并查看两条曲线。歌声音源在滑音区跟随目标音高，两端与自然音高交融，并叠加颤音。保存后仍可逐点编辑，或一次撤销。使用滑音后，`agent-vocal/5` 工程和 avpack 会保留曲线及混合权重。MCP 用 `selection_edit` 的 `pitch_join`，可用 `tuning_audition` A/B 试听。

只选一个歌声音符时，「滑音」可调整「起音」或「尾音」。负音分让起音从低处上滑，或让尾音向下收。长度为 20–2000 毫秒，且在当前音符时值内。偏移叠加在已有音高曲线上，保留原有颤音、咬字和时值。MCP 用 `selection_edit` 的 `pitch_edge`，传 `side`、`length_ms` 和 `offset_cents`。

选中一个歌声音符，点「颤音」。起止为音符时值百分比，淡入淡出按速度表内的实际毫秒。曲线图标出预计颤音的区间，试听默认对照同一歌手的原电平局部干声。确认应用只写该音符的颤音，保留手绘音高、歌词、时值和咬字，可以一步撤销。旧工程沿用默认的 80 ms 淡入。使用扩展包络时保存为 `agent-vocal/18`，可通过 avpack 保留。

MCP 用 `selection_resolve` 选定音符，再用 `selection_edit` 的 `vibrato_envelope` 预览。传 `settings: {depth,rate,start,end,fade_in_ms,fade_out_ms}`，其中 `start`、`end` 为 0–1 的比例。当区域太短且两端淡化重合时，预览回报的最大包络深度会低于请求值。一个长词可先直唱，再试晚进、提前收住的版本，依词意和下句入拍复听。 [流行唱法中的颤音观察](https://pubmed.ncbi.nlm.nih.gov/26700395/) · [歌手颤音起点的差异](https://www.internationalphoneticassociation.org/icphs-proceedings/ICPhS1999/papers/p14_0981.pdf)

外部 Agent 可用 `tuning_audition` 完成同一流程。它支持滑音、参考调声、颤音、落字，以及通过 `set` 调整音高、曲线、咬字、歌词或力度。

1. 选好音符后，用 `agent_focus` 说明目标，再调用 `tuning_audition` 的 `prepare`。传工程 ID、版本、选区 ID、音源和调声变换，可传 `intent_id`。默认用原电平局部干声。需要听伴奏上下文时设 `local_voice:false`，参考调声在该模式下试听经过混音链的目标歌声。
2. 用 `status` 查询回执。回执丢失时可按工程与版本查询当前任务，或重传相同准备请求。完成后可用 `measure` 读取试听文件本身的电平。本地干声还可按音符查看可靠音高偏差的 10、90 百分位。分析区间须在该试听对内，每次最多 12 秒。桌面用带票据的 `desktop_transport` 切换 A 或 B。
3. 确认时给 `selection_edit` 传 `selection_id`、`expected_revision`、`audition_id` 和 `dry_run:false`，以试听时冻结的操作一次保存。应用会释放同一对试听。工程改版时可用原版本和准确 ID 释放旧回执。取消渲染用 `cancel` 后查询终态。

选同一歌声轨的音符，点「参考调声」，选择覆盖选区且按工程起点对齐的单声部干声。一次最多 32 个音符或 15 秒。预览显示可应用和略过的数量，A/B 只试听同一歌声音源用原曲线和参考曲线的合成。声音不稳定或与谱面音高相差过大时略过。MCP 用 `selection_edit` 的 `pitch_reference` 和 `reference: {track_id, clip_id}` 先预览。音高通过基频估计得到。 [YIN 原始论文](https://www.ee.columbia.edu/~dpwe/e6820/papers/deChevK02-yin.pdf)

画出预览后，点「试听」对照同一段的「A 原版」和「B 滑音」，保留原电平。初次点击播放 B，切换时沿用对应拍位。更新参数、关闭面板或应用滑音会结束当前试听。已有同版混音时直接用它作 A，B 只在试听中合成。

应用整轨试听过的草稿后，如果下一次渲染的歌声输入完全一致，渲染会复用试听时的 VOICEVOX 人声原始采样。正式导出按保存的音轨、效果器和总线处理。试听原始采样在当前进程最多缓存 96 MiB，命中会写入 `render_status.result.reused_preview_voice_track_ids`。

「参考调声」的 A/B 默认开启「局部干声」，只合成试听范围和相邻音节。延续元音的音节会连同开头一起送入引擎，音符落拍继续使用工程速度表。「滑音」也可手动打开此选项。关闭后可按原整轨流程试听。局部音频用于比较调声，正式渲染沿用整轨合成和混音。

### 外部 Agent 接入

使用工作区的 `bin/agent-vocal-studio.exe --mcp --home <Studio目录>` 作为 stdio MCP 服务。Codex 可运行 `注册Agent接口.ps1` 注册。其他客户端使用相同的可执行文件和参数。模型与对话由客户端提供。

外部 Agent 先读工程和版本，使用 `agent_focus` 在 Studio 标出实际目标。指定选区时，音符走 `selection_resolve` 和 `selection_edit`，多轨拍范围走 `arrangement_query`、`arrangement_edit` 和 `arrangement_audition`。工程级批次可用 `project_preview` 检查谱面差异，确认后用 `project_edit` 保存。应用后读回工程，再试听或导出。

版本冲突通过 MCP 返回 `isError:true` 和 `structuredContent.code:"REVISION_CONFLICT"`，同时保留文字说明。收到冲突后，重新读取工程和目标范围，再生成预览。

### 开发顺序

1. 稳定对外 MCP。在 Codex 和另一个独立 stdio 客户端验证读取工程、使用用户框选、预览和提交修改、撤销、试听、保存及导出。用双客户端同时编辑验证版本冲突，并确认人工接管后旧播放控制凭据失效。
2. 打磨桌面编辑和监听。优先多轨框选、音频剪辑、调声、混音和快捷键。用长工程检查编辑和播放响应。主界面使用近黑中性色，饱和色用于轨道。保留可拖动的标题栏和窗体阴影。外部智能体操作时，发光圆角三角指向实际目标，标签显示操作和进度。
3. 用可编辑歌曲贯通制作与交付。用外部智能体完成核心乐句、伴奏、调声和混音，按听感返修。重开工程并核对历史、素材、混音和分轨能否继续使用，然后发布通过验证的 Windows 包。

在编排区框选歌声、乐器和音频，打开「复制片段」「移动片段」或「清除片段」。固定秒数的伴奏跨过框线时，预览会标出截取数量。复制只在目标处建立引用，移动或清除只改框内窗口，框外音频、完整的淡化和源文件保留。所选轨一起提交，可以一步撤销。音符和拖腔要完整框入，边界也要避开淡化区与跟速、对拍片段的内部。移入变速区时，固定秒数的片段仍保留时长，超出目标范围会提示扩大范围。MIDI 控制点、音量自动化、速度、拍号和段落标记按工程拍位生效。

MCP 先用 `arrangement_query` 核对各轨和段落，再调用 `arrangement_edit` 指定音轨 ID 与拍范围，携带 `preview_id` 提交。传 `slice_audio:true` 截取固定秒数片段，回执的 `clip_change.cuts` 给出工程采样帧、素材源帧和留在原位的片段数。复制或移动后默认在目标范围和当前版 A/B，清除时在原范围 A/B。

多轨移调用 `action:"transpose"` 和非零整数 `semitones`，在 `source` 原拍范围内移调，预览返回每轨的 `pitch_range` 和涉及的原声轨。鼓轨、音频、和弦标记以及音符原有的歌词、时值与相对调声随工程保留。整组延音须一起框入。结果超出 MIDI 0–127 时整次预览会指出轨道和音符。移调后的实际音域请结合歌手、乐器和 A/B 试听确认。

多轨量化用 `action:"quantize"` 和 `quantize:{step:0.25,strength:0.75,swing:0.5}`。四分音符为一拍，50% 摇摆表示等分网格，网格从各小节开头重算。歌声、乐器和鼓的音符保持时值，延音与同一个字的起音一起移动。音频片段和自动化保留原拍位。音符重叠或越过选区时，预览会提示调整参数或选区。

编排的复制、移动、清除、移调、量化，以及片段的交叉淡化、跟速和对拍，都可在各自的面板先预览，再点「试听」。A 和 B 用同一工程拍段播放经过原音轨、编组、效果和主总线的混音。默认用原电平。有同版本混音时复用 A。试听后点「应用」提交已听到的草稿，一步可撤销。

MCP 用 `arrangement_audition` 传入上述预览的 `preview_id`。编排范围传 `edit: {kind:"range",edit:{action,track_ids,source,target_start?,slice_audio?,semitones?,quantize?}}`，片段组传 `edit: {kind:"clip_group",edit:{clips,action}}`。默认在目标位置或接缝附近取段，也可给出精确 `beat_range`，每侧最长 45 秒。用 `status` 查回执，`desktop_transport` 切 A/B。用 `measure` 读取同一对试听文件的电平，交叉淡化还返回两端相邻采样的幅度跳变。当你确认应用时，用 `apply` 传同一对的 `audition_id`、`preview_id` 和原版本。

在游标处按 `Ctrl+O` 导入音频到新轨，或选中音频轨，点「＋ 音频」添加片段。支持 8–192 kHz 的单声道或立体声 WAV、MP3、FLAC，单个素材最长 15 分钟。应用将每份素材解码为工程内部的 48 kHz 立体声浮点 WAV，供波形、剪辑、播放与打包使用。MP3 和 FLAC 由内置解码器读取。 [Symphonia 0.6.1](https://docs.rs/crate/symphonia/0.6.1)

MCP 用 `audio_import` 绑定工程 ID 和版本，通过绝对路径流式导入。传入 `track_id` 可添加到现有音频轨，`start` 以四分音符拍定位。也支持 `filename` 和 `data_base64`，数据大小上限为 128 MB。

音频编辑用 `audio_clips` 读取片段 ID 和范围，再用 `audio_clip_edit` 预览与提交。源偏移、长度、裁剪和淡化以 48 kHz 样本帧表示。工程包保存转换后的源音频和片段窗口。

按住 `Shift` 拖动可跨音频轨框选，`Ctrl` 点击可增减片段。拖动任一选中片段时整组移动。`Alt` 拖动或 `Ctrl+D` 复制，`Ctrl+C` 和 `Ctrl+V` 可从组起点粘贴到游标处。Agent 可用 `audio_clips` 的 `from_ui` 读准确片段，再用 `audio_clip_group` 预览和提交。整组修改占一个撤销步骤。

同轨选两个片段，点「交叉淡化」。已有重叠时用完整重叠区，包括跟速和对拍后的片段。两段都跟速时，淡入淡出按重叠拍数保存，改全局速度后，两边仍共用一个采样区间。固定秒数与跟速片段也可在当前速度下做交叉淡化，改速后可以重新试听并计算接缝。

首尾相接的固定秒数片段可从源文件余量向接点扩展，时长留空时最多扩展 20 ms。对首尾相接的跟速片段，先建立重叠再淡化。对齐的同源固定切片默认使用线性，其余默认使用等功率，也可手动选择。MCP 使用 `audio_clip_group` 的 `crossfade`，从 `transition.frame_range` 查看接缝帧，`audio_clips` 的 `fade_edges` 返回淡入终点和淡出起点，可在片段面板做 A/B。拍淡化保存为 `agent-vocal/19`，AVPACK 可保留。

选中一个或多个片段，点「跟速」，可用当前拍数、指定目标拍数，或给出源文件的 BPM。片段随后按速度表伸缩，使用波形相似重叠相加处理音高，桌面播放沿用离线渲染及缓存。要恢复源文件秒数，选「固定秒数」，已有拍淡化会按原映射转换到源帧。MCP 使用 `audio_clip_group` 的 `tempo`，桌面跟速面板支持 A/B。跟速设置保存在 `agent-vocal/7` 工程及 avpack。 [WSOLA 论文](https://researchportal.vub.be/en/publications/an-overlap-add-technique-based-on-waveform-similarity-wsola-for-h/)

选中单个片段，点「对拍」。点击波形上方的灰色起音刻度，或从「起音」菜单选一个位置。也可双击源波形任意位置。拖动下方标记选择目标拍位，也能在列表里键入数值。预览后应用，支持一次撤销。源位置从当前源窗口起点计算，相对拍位从片段起点计算。对拍点分段控制伸缩，首尾由片段总拍数决定。切到「固定秒数」会删除内部点。

MCP 的 `audio_waveform` 支持 `include_transients:true`。每个候选含 48 kHz 的片段相对 `frame` 和按当前速度、对拍映射计算的工程 `beat`。可用 `frame_range:[first,end]` 缩小源窗口，每次最多返回 96 个。候选基于短时多频带能量上升，缓慢起音、密集连奏和整曲伴奏需要结合试听判断。 [Bello 等关于音乐起音检测的论文](https://doi.org/10.1109/TSA.2005.851998)

Agent 用 `audio_clip_group` 的 `warp` 操作预览并提交完整对拍点列，在桌面片段面板可在改动附近 A/B。工程包保留对拍点。

## 和弦标记

编排工具栏的「和弦」可按拍位写入和弦符号，如 `Cmaj7/E`、`Dm9`、`G7(♭9,♯11)`。斜杠指定低音，`N.C.` 表示留空。和弦显示在编排尺上，双击该行可回到对应标记。框选时改的是这个拍区间，结束边界会恢复原和弦。

Agent 可用 `harmony_query` 读取拍位、根音和指定低音。标记保存在原生工程及 avpack。乐句复核会标出值得听的持续音与和弦变换位置，音符、配器和实际发声仍由曲谱决定。 [Berklee 和弦类型与符号参考](https://assets.online.berklee.edu/handbooks/berklee-online-music-theory-harmony-and-ear-training-handbook.pdf)

使用 MCP 的 `voicing_preview`，可比较紧凑和开阔两种上声部配置。各声部的进拍、时值和力度由请求明确指定，指定低音沿用斜杠音。可选主唱音轨作为声部间距参考。建议本身为只读，选定的音符可放入乐器轨草稿，和主唱一起 A/B 后再应用。 [Berklee 键盘配置与声部连接](https://assets.online.berklee.edu/handbooks/berklee-online-piano-handbook.pdf)

## 乐句复核与返修

在编排框选音轨和拍范围后打开「复核」，可逐句查看落字、谱面间隙和琴鼓入场，点「定位」回到对应拍位。乐句按约 300 ms 的谱面间隙分组，实际词意、重音与换气仍需听审。乐器入音按音符计数，同拍和弦可计多个音符。音频片段里的演奏需单独试听。

点乐句中的歌词可在卷帘中框定该字对应的音符。拖腔显示成一个带「〜」的落字，段落的歌声入音密度只计新落字。范围从字的中途开始时，显示「〜」及范围内的时值。MCP 从 `syllables` 读取对应的拍区间和稳定音符 ID，从 `notated_seconds` 读取按速度表计算的谱面时长，用咬字分析另外核对引擎的发声时序。

点击一句旁边的「对照」，可在同一拍位切换「A 全混」和「B 人声轨」。使用同一版混音后导出的分轨，保留相同的总线限制器增益。编组歌声显示「B 编组」，播放完整编组输出。默认用原电平复核遮盖，判断咬字或音色时可选择匹配响度。独立的共享混响或延迟返回进入全混，MCP 可明确将其加入一侧。只有混音 WAV 的归档没有独立分轨。

打开同段对照后点「电平」，可按拍查看人声和其余混音在 1–4 kHz 的原电平，点任一拍段进入该段 A/B。测量按工程速度表对齐，使用双声道 RMS 和采样峰值。1–4 kHz 采用串联的高通与低通，作用是定位值得试听的同频段能量。 [W3C 双二阶滤波公式](https://www.w3.org/TR/audio-eq-cookbook/)

MCP 用 `render_balance` 绑定当前 `project_id`、`expected_revision` 和已完成的 `job_id`。在 `request` 指定拍范围与 `focus` 输出列表。可选 `reference_outputs` 比较指定的另一组输出，或用 `include_remainder:true` 比较全混扣掉焦点后的其余声音。每次读取最长 45 秒，默认半拍一格，后台最多保留 64 格并回报实际格长。选区模式适用于选中拍段内的直出轨，分析整份混音、编组或共享返回时使用「整个工程」。数值用于定位复听，实际辨词和取舍靠试听。

只在选区修改音符时默认用局部干声，已有实音测量时优先监听测量用的混音或分轨。局部模式只合成目标歌声和相邻音节，即使工程里的曲谱轨静音也能试听。切到「全混音」可核对伴奏、推子、效果器和总线。两种模式分别复用已准备的音频，应用仍由你确认。

两份草稿也可传同一个 `output:{kind,id}` 测量指定输出。直出轨用 `track`，编组用 `group`，共享返回用 `return`。直出轨按框选授权，编组和返回需要整个工程。该输出取自完整混音链，保留原有的效果、声像、自动化、旁链和主总线处理结果。试听面板可在实测分轨和全混音之间切换，两种监听分别复用已准备的音频。

在「复核」里选有 4–16 个完整音符的一句，点「动机」看同一歌声轨上的回归。结果并排给出拍位、移调、节奏比例、句尾变化、歌词、已写和弦和可见伴奏入音。可以定位回归点，或点「查全曲」扩大当前手动查找范围。 [流行歌动机回归与句尾变化](https://www.mtosmt.org/issues/mto.22.28.3/mto.22.28.3.nobile.html)

「曲谱复核」里的「段落对照」支持作品设计中的段落和自定义拍范围。对照配器进退、主唱留白、伴奏入音和谱面音区重叠。拍长与拍号布局可比时，另显示律动重合度，鼓组按起拍和鼓件比较。点听点用同一版本的混音做两段 A/B。已有该版本的混音时直接复用。谱面指标用于定位，音频轨显示素材覆盖。

有可用主唱时，「主唱首字」和「主唱尾音」各自对齐 A、B 段的唱入或结束。选听点后点「原电平」可查看同版混音截取出来的响度、宽带 RMS，以及有直出分轨时的主唱与其余混音 1–4 kHz 相对电平。MCP 在同一 `section_contrast` 请求里加 `job_id` 和从 0 开始的 `audio_cue`。整份混音需要覆盖全部音轨，精确拍区间返回在 `audio.beat_ranges`。先确定这段要拉开哪种表达差异，再选择保持原电平或匹配响度来听。

「鼓贝斯」按当前速度表显示底鼓、贝斯的谱面入音和相对毫秒数。负值代表贝斯在前，正值代表贝斯在后。贝斯延音盖过底鼓也会注明。点播放可对照节奏组分轨和全混音，点「调整」可预览单个贝斯音符的新落点和音长，应用后可撤销。谱面时差用于定位，音色起音、切分与律动由实音复听判断。 [Swing 与 Funk 演奏微时差研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5050221/)

点任一回归旁的「试听」可在同一份混音中循环切换 A 参照、B 回归。引擎优先使用当前版本已经渲染的混音，首次需要时会先渲染。切换时按区间内相对拍位换段，两段各按原速度播放。可选匹配响度或原电平。关闭复核后停止并释放临时片段。

MCP 的 `motif_returns` 用音轨及首尾音符 ID 定义参照。可传 `beat_range` 和 `track_ids` 缩小范围。查找比较前段音程和入拍，给出统一移调、节奏比例及最后一音的变化。

Agent 可用 `range_audition` 的 `prepare` 操作从当前工程版本的已完成混音中提取任意两个拍范围。传 `job_id`、`beat_ranges`，每段最多 45 秒。播放先读取 `desktop_transport` 状态获取票据，再用 `audition_side` 选择 A 或 B。完成后用 `range_audition.release` 释放对应 `audition_id`。试听增益只进入临时片段。

比较两个已完成渲染时，传入两个 `{project_id,revision,job_id}` 对象组成的 `renders`，以及各自的 `beat_ranges`。至少一边对应桌面当前打开的工程版本。比较同一个乐句时，两边传相同拍范围，各自按渲染所用的速度曲线定位。传 `level_match:false` 可保留两边的原始电平。

复核和录音对照准备好后，可点「导出 A/B」。MCP 在释放试听前调用 `range_audition` 的 `export`，传入同一 `project_id`、`expected_revision` 和 `audition_id`。ZIP 包含实际试听的两份 48 kHz / 24 bit WAV 和 `试听清单.json`，记录来源版本、拍段、采样边界及试听增益。ZIP 在释放试听后仍可打开。

比较同一句的不同输出时，为 `beat_ranges` 两边传同一拍范围，并加上 `outputs: [null, [{"kind":"track","id":"歌声轨 ID"}]]`。一侧的 `null` 使用完整混音。分轨列表可用 `track`（直出轨）、`group`（编组）、`return`（共享返回），按 ID 明确选定。合并分轨发生超峰时，两侧共用回执中的 `source_trim_db` 留出余量。使用 `level_match` 开关响度匹配。试听只读同版渲染，产生临时音频。

## 录音

桌面传输栏的圆形按钮或 R 打开录音。选输入设备、单声道或一对相邻通道，设置目标音轨和拍位，再开始录音。停录后可调整拍位或目标轨，点击「导入工程」才会写入项目。停止后保存的待导入录音可以在重启时恢复。片段时长受工程 15 分钟上限约束。

录音通过 WASAPI 采集，按 48 kHz WAV 放入工程，单声道内容在左右两侧使用同一信号。导入后可用 MCP 查看、调整和导出。麦克风由桌面用户启停。

传输栏的节拍器按钮或 `M` 切换普通播放的节拍监听。小节首拍有重音，6/8、9/8、12/8 等复拍按三枚八分音符分组。速度曲线、变拍号和循环使用工程时间轴。节拍声走桌面监听，混音导出使用工程音轨。

录音面板的「节拍提示」可单独使用，也可和「随伴奏录音」一起使用。「预备」长度为 0–8 个四分音符拍。从工程零拍开录时，预备拍会用工程开头的速度和拍号从零拍前播放。设备时间戳用于定位入点，导入工程时裁掉入点前的输入采样。MCP 的 `timeline_query` 可用 `pulse_range` 读取节拍的源帧与重音，起点最低为 -8 拍，每次最长 45 秒。 [节拍提示与预备拍的工作流参考](https://www.steinberg.help/r/cubase-pro/15.0/en/cubase_nuendo/topics/playback/playback_metronome_c.html)

在编排区框选两遍录音共同覆盖的一段，点「录音 A/B」。试听沿用同一拍区间，保留片段增益和淡化，取自轨道效果与推子之前的素材。可试听原电平或匹配响度。选择拼接轨，点「收录 A」或「收录 B」，把该段复制到相同拍位，保留原始录音。之后可以在同一拼接轨接上另一遍的选段，或对相邻片段做交叉淡化。适用于固定秒数的片段，每次 A/B 最长 45 秒。收录时边界要落在片段的淡化区之外，或保留完整淡化。 [录音选段拼接的工作流参考](https://www.ableton.com/en/live-manual/12/comping/)

MCP 的 `range_audition` 接收两份 `recordings:[{track_id,clip_id},…]` 和相同的两个 `beat_ranges`，可直接准备比较。使用 `desktop_transport` 切换和停止。用 `audio_clip_group` 的 `{kind:"extract",beat_range:[start,end],to_track_id?}` 预览并提交单个录音的选段，省略目标会新建拼接轨。修改绑定工程版本，可一次撤销。正常播放遵循混音器中的静音与独奏设置。

勾选「随伴奏录音」后，可提前播放 0–8 拍。系统播放当前工程版本的混音，并用输入和输出的 Windows 时间戳估算录音入点。正的延迟校正值会把录音向前移，负值会向后移。留在待导入状态的素材可调整目标轨和拍位。当前校正由用户输入，实体输入输出链路的往返延迟仍待现场验证。

## 音量曲线

在编排工具栏打开「音量曲线」，选择音轨，双击图面添加点，拖动或键入精确的拍位和 dB。框选音轨和时段后再打开，选区两端会固定在原电平。点的 dB 值叠加到推子，位于轨道插入效果器之后、总线限制器之前。锚点随速度表定位，在两个锚点之间按时间对线性增益插值，首尾之外保持最近点的值。

MCP 用 `gain_automation_query` 读回曲线和指定范围的边界电平，`set_gain_range` 作为 `project_edit` 中的一项操作写入严格位于范围内的 `{beat,db}` 点。整轨替换用 `update_track.values.gain_automation`。保存只更新混音图，已经载入实时混音的播放可以继续。工程包 `agent-vocal/11` 保留可编辑曲线，音频导出包含处理后的电平。

## 子音与元音落拍

选中歌声音符，在「咬字」里点「分析咬字」。子音时长可设为 1–300 ms，留空恢复引擎预估。需要稍微抢拍或拖拍时，单独设元音偏移，范围为 −120 至 +120 ms。偏移会带着子音一起移动，谱面拍位和音高参数保持原样。界面显示按引擎帧和相邻音素限位后的实际偏移。元音最早落在工程起点，工程起点前的子音会被裁掉。更换歌词会恢复两项默认值。

MCP 用 `pronunciation_query` 读取当前版本指定音符的时序，再用 `update_note` 或 `selection_edit` 写入 `consonant_ms` / `vowel_offset_ms`。元音偏移保存在 `agent-vocal/10` 工程和 avpack，导出 MIDI 时只保留谱面。

## Agent 控制桌面试听

1. 用 `desktop_transport` 的 `status` 读桌面当前工程、版本和 `ticket`。返回 `attached: false` 表示桌面窗口未连接。
2. 同版本渲染完成后，发送 `action: play`，传入 `ticket`、`project_id`、`expected_revision`、`job_id`、`beat_range` 和简短的 `reason`。范围用四分音符拍，默认播放一次，`repeat: true` 启用循环。钢琴卷帘和编排画布会标出复听段落。
3. 用新 `ticket` 操作 `pause` 或 `stop`。你操作播放栏或游标时优先接管。通信超时后先查 `status`，可核对 `owner`、`playing`、`seconds` 和 `audio_frames`。

试听回执能验证设备回调和播放位置。创作听审仍需要实际听到音乐。

## 混音效果器

`F3` 选择要压低的音轨、编组或返回，添加「旁链闪避」，再选触发音轨。触发信号取自音符或片段渲染后的原始轨，位置在效果、推子、声像、音量曲线和静音之前。静音的鼓轨也能专门触发。阈值、最大衰减、比率、启动和释放可在试听时调整。混响返回也可借此在唱词间隙抬起来。 [Ableton 对外部触发与闪避的说明](https://www.ableton.com/en/live-manual/12/live-audio-effect-reference/#compressor)

Agent 从 `effect_catalog` 读取 `ducker`，将触发轨的 ID 写进 `source_track_id`，随目标的完整效果链提交。渲染报告在 `track_effects`、`group_stems` 或 `aux_returns` 给出对应通道的 `ducking_max_reduction_db`。要删除触发轨，在同一批编辑中先移除指向它的效果。旁链设置保存在 `agent-vocal/17` 与 AVPACK。

录音环境声或换气较响时，可在效果链添加「向下扩展」。它使用两声道的共同峰值检测，按阈值、比率与软拐点逐渐降低小信号，最大衰减限制处理深度。保持和关闭时间决定句尾收下去的速度，开启时间决定下一句恢复的速度。用同段 A/B 检查轻字、换气和起音。实时试听和导出共用处理器，起音恢复受开启时间影响。 [扩展动态控制](https://www.fabfilter.com/help/pro-g/using/dynamiccontrols) · [保持、开启、关闭和软拐点](https://www.fabfilter.com/help/pro-g/using/timecontrols)

Agent 从 `effect_catalog` 读取 `expander` 默认值，向指定音轨、编组或返回的有序效果链提交。导出后从 `track_effects`、`group_stems` 或 `aux_returns` 读取 `expander_max_reduction_db`，它记录输入有信号时的最大实际衰减。设置保存在 `agent-vocal/20` 与 AVPACK。

`F3` 后选择音轨或总线。音轨最多八个插入，可更改顺序、旁路或删除。播放当前版本后，调参数时会进入实时监听。关闭面板可还原草稿，应用后继续播放。已有旧版混音时，用「应用并试听」生成原始轨。实时总线使用零前瞻的采样峰值保护，导出按工程设定的前瞻处理。延迟和混响的尾音随工程所设的尾音时长输出。

Agent 用 `effect_catalog` 读取参数范围，通过 `project_edit.update_track.values.effects` 替换指定轨道的有序效果链，用 `set_project.values.master_limiter` 设置总线限制器，传 `null` 清除。效果参数存入 `agent-vocal/4` 工程与 `avpack`。Agent 的指定区间复听绑定已经发布的同版本渲染。

共享发送在插入、音量曲线、推子和声像之后取信号。最多四条返回通道，每条有自己的插入链和返回电平。混响和延迟预设设为全湿。主轨和返回一起进入主总线，离线总线限制器的增益会同时应用到对齐的分轨。渲染报告的 `aux_returns` 关联返回 ID 和单独的 WAV 文件。尾音受工程 `tail_seconds` 控制。[Ableton 对返回与推子后发送的说明](https://www.ableton.com/en/live-manual/12/mixing/#return-tracks-and-the-main-track)

Agent 用 `project_read` 读取当前返回及各轨发送，用 `effect_catalog` 查字段和范围。通过同一次带版本的 `project_edit` 提交 `set_project.values.aux_buses` 与 `update_track.values.sends`。两个字段都替换完整列表。移除返回时，同一批次移除引用该返回的发送。这些设置随 `agent-vocal/13` 和 `avpack` 保存。

最多八个编组，可分别调电平、静音和插入链。组内成员经过各自轨道设置后相加，再经过编组插入链和推子，合计一路到总线。每条轨道的独立发送取自编组处理前，编组静音会停止成员向返回送入新信号。现有编组之间改派成员时，桌面会平滑过渡。[Ableton 混音分组说明](https://www.ableton.com/en/live-manual/12/mixing/#group-tracks)

`effect_catalog.mix_groups` 描述组设置，`project_edit.set_project.values.mix_groups` 替换组列表，`update_track.values.output_group` 写入组 ID 或 `null` 回到总线。移除组时同一批次清除成员分配。存档为 `agent-vocal/14`。导出用一条组后 WAV 代表整组，回执 `group_stems` 关联组 ID 与文件，叠加直出轨和效果返回可组成混音。原始成员及素材留在可编辑工程里。

导出后状态栏显示整段响度 LUFS 和真峰值 dBTP。MCP 通过 `render_status.result.loudness` 查看 400 ms 瞬时最大值、3 秒短时最大值、真峰值的声道和估算秒位。指标从最终的 48 kHz 立体声 24 位 WAV 采样计算。整段响度使用 K 加权与绝对、相对两道门限，真峰值用四倍过采样。静音或短到没有完整测量窗口时，相关字段为 `null`。 [ITU-R BS.1770-5](https://www.itu.int/rec/R-REC-BS.1770-5-202311-I)

按 `F3` 打开总线限制器，检测方式可选采样峰值或「真峰值 · 导出」。真峰值模式设定 dBTP 上限，通过四倍检测和前瞻、释放降低峰值附近的增益。内部留出 0.2 dB 余量。如处理后的信号仍超过内部目标，引擎会同量降低混音和所有对齐分轨，并复测最终 WAV。普通播放使用零前瞻采样峰值限制。要核对实际的导出真峰值，在命令面板选择「试听真峰值混音」，播放当前版本渲染的 WAV。 [EBU 真峰值制作指南](https://tech.ebu.ch/publications/tech3343)

Agent 在 `set_project.values.master_limiter` 写入 `peak_mode: "true_peak"`，其 `ceiling_db` 使用 dBTP。省略 `peak_mode` 使用既有的采样峰值模式。真峰值配置存于 `agent-vocal/15` 与 avpack。用 `render_status.result.master_limiter` 查看最大衰减、内部余量与最终修正，再从 `result.loudness.true_peak_dbtp` 核对文件实测。

可切到 RMS 或取消匹配来核对原电平。不足 0.4 秒且双方有信号时，用 RMS 并显示原因。低于响度门限时保留原电平。试听增益只用于 A/B。

`render_start(prepare_monitor=true)` 为桌面预听准备包含静音轨的原始轨缓存。静音及独奏外音轨保持静音，导出分轨按最终混音状态生成。音源都已准备时，切换 M/S、拉推子或调整声像会沿用正在播放的音源和游标。遇到无法准备的音源或容量不足时，仍可使用已渲染的混音试听。

## 深色界面验证

命令面板使用 Pico CSS 2.1.1 的条件样式。工具栏、浮层和面板共享深色玻璃材质，轨道用高饱和颜色区分。`--verify-theme` 在 WebView2 中采集文本、图标、控件边界和焦点的对比度，并采样钢琴卷帘和编排画布。报告写入 `verification/theme_report.json`。 [Pico CSS](https://picocss.com/docs) · [WCAG 文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [WCAG 非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 当前边界

当前是歌声单声部、采样乐器复音的编辑器。试听使用 WASAPI 共享模式。停止播放后，可用传输栏的「音频输出」选择设备或继续跟随 Windows 默认。设置按工作区保存，下次播放时打开所选设备。MCP 的 `desktop_transport` 用 `action:"devices"` 读取可用设备、配置和实际输出。48 kHz 设备直接读取源采样，其他设备由 Rust 用 128 点窗化 sinc 转换。混音、A/B 两侧及实时分轨共用采样时钟及滤波方法。循环按区间首尾取样，一次性选区只读取选区内的音频。 [Julius O. Smith 的窗化 sinc 采样率转换](https://www.dsprelated.com/freebooks/pasp/Windowed_Sinc_Interpolation.html)

桌面点「播放」会直接准备干轨并实时混音。已有音轨缓存会复用，缺少的歌声、乐器或伴奏在后台准备。当前试听音源仍由工具栏决定。首次使用 VOICEVOX 或 OpenUtau 时，需要等待对应引擎合成。导出 WAV、归档混音和命令「试听真峰值混音」使用正式渲染。

超过 30 秒的已渲染混音由后台预读。为滤波保留页边缘的采样，并预读循环首尾，常驻 PCM 缓存每轨最多约 0.94 MiB。磁盘较慢时，播放会在当前采样位置等待数据。A/B 和录音对齐使用内存中的音频。

实时分轨监听支持 8–96 kHz 输出设备。超过 30 秒或干轨合计超过 16 MiB 时，系统按同一时间窗预读分轨。推子、效果链、旁链和总线从同一采样位置取信号。使用 `render_start` 的 `prepare_monitor:true` 准备静音与独奏之外的轨道，以便播放中调整。MCP 的 `desktop_transport` 状态报告 `streaming`、`buffering`、`buffer_wait_frames` 和 `live_streaming`，`live_buffered_frames` 是各干轨缓存的立体声帧之和。

监听期间修改现有音轨的谱面或音频片段，在速度、总帧数和监听声部兼容时，后台只重新生成变更的干轨。新版本接入当前播放位置，保留循环及已建立的混音处理状态。连续编辑时以最后一版为准。暂停时更新后仍保持暂停。MCP 读取 `monitor_revision` 确认当前实际监听的版本，`monitor_refreshing` 表示后台准备中。涉及工程时长、速度或总线路由结构改变时，重新按播放准备监听。

使用 VOICEVOX 监听时，局部改谱会尝试在新旧两版都留有休止的位置接入新乐句。整字的起音和延音一起处理，接缝两侧须通过电平检查。最多替换 8 秒，`monitor_local_frames` 返回该次更新实际接入的帧数。连续唱段或接缝电平偏高时，后台更新整条干轨。正式导出按完整工程渲染。 [VOICEVOX 歌唱合成接口](https://github.com/VOICEVOX/voicevox_engine#歌唱音声合成)


原生 `agent-vocal/2` 工程保留速度曲线和拍号表。第一次剪辑伴奏时升级到 `agent-vocal/3`，原轨可继续读取，撤销能恢复剪辑前的工程。新导入片段默认固定秒数，可切换到跟速或手动对拍。MIDI 用离散事件表达渐变速度。变速 PPSF 仍待适配。

VOICEVOX 是其他歌手，不是初音未来。歌声主要使用日语逐音假名；各音源有自己的使用条款与署名要求，导出会保留相关信息。
重新合成时，VOICEVOX 可能为同一曲谱预测不同的音高和音量曲线。确认试听后，在命令面板选择「另存带混音的工程包」，把当前版本的立体声 WAV 与可编辑曲谱一并保存。导入后用「试听归档混音」播放该版本的 WAV。带混音的工程包上限为 128 MB。
Agent 可在 `project_export` 的 AVPACK 请求中传入 `expected_revision` 和 `mix_job_id`。导入回执包含 `archived_mix`。重开时使用 `render_jobs` 的 `archived_only:true` 和相同工程版本定位该混音。修改工程后，归档 WAV 仍保存在原包中，新版本按当前曲谱生成试听。
MIDI 保留乐器程序、复音和已支持的踏板/表情 CC；不保留本软件全部调声，跨电脑请优先保存 avpack。PPSF 导入前显示歌声轨、音符数量、BPM、拍号和需单独迁移的内容。Agent 可用 `project_import` 的 `dry_run: true` 获取迁移摘要，再将摘要中的 `source_sha256` 作为 `expected_source_sha256` 提交。Piapro 专有调声、缓存、音色及伴奏需重新配置或单独导入。

导入 PPSF 时可同时选择从工程起点导出的原版人声和伴奏（WAV、FLAC 或 MP3）。分轨从第 0 拍对齐，保存为独立音频轨。选了原版人声时，可编辑歌声轨初始静音。试听新合成可静音原版人声并启用曲谱轨。MCP 在确认请求里用 `reference_audio.vocal_path` 或 `reference_audio.backing_path` 传绝对路径。
