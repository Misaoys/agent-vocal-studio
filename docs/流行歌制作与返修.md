# 流行歌制作与返修

先问这首歌为什么值得存在。用一句话说清楚谁在什么处境里做了哪件事，又有什么话说不出口。参照曲只注明可借鉴的制作手法，例如主歌的低频留白、歌词递进、鼓和贝斯的交错、或副歌的反差。保留本曲自己的旋律、词与演唱性格。

## 从问题决定怎么做

| 听到的问题 | 试这两种走向 | 决定保留什么 |
| --- | --- | --- |
| 钩子唱完就忘 | 同一句分别试弱起切入和停一拍后进入，给两个版本不同的句尾落点。 | 关掉复杂配器，还能哼出哪个节奏。反复出现时，是否能在另一句里听出它的发展。 |
| 歌词像通用情绪文案 | 先写一个只能发生于此人的动作。再试删掉一句解释，让下段的新信息重释前一句。 | 保留有叙事职责的物件、字词和停顿。读一遍，再照旋律唱，检查重音、长元音和换气。 |
| 副歌到来时没有落差 | 一版用内声或底鼓铺出预期，另一版撤掉低部、先让钩子独唱半句。 | 副歌需要释放、压住还是把答案放到后面，由歌词转折和听感决定。 |
| 段落越来越满 | 一版让器乐在空拍接句，另一版只用贝斯方向和和声换拍推动。 | 分清主唱前景、和声内声、节奏支撑、应答与空间。静音一条轨后听哪里失去了作用。 |
| 鼓和贝斯像整段复制 | 保留节奏的辨识度，用贝斯音长和底鼓停顿回答换气；在关键回归处改过门或细分。 | 保留可跟随的律动，变化跟乐句发生关系。检查鼓组组合能否自然演奏。 |

歌词、曲式和配器的选择可反复往返。近讲语气的主歌、升高音区的副歌是一种选择。稀疏的副歌、器乐随后接过钩子也能成立。第二遍可以保留同一个钩子，把意义交给新歌词或新背景。保留简单而有辨识度的材料，删掉抢主唱的复杂层。

复核反复出现的一句时，先读工程里绑定的原词，核对这一次有没有新的动作、对象或信息。保留真正承担辨识度的词，再把新词落到适合的停顿和长音上。遇到「核对读音」时按当前落字试听，确认长元音和断句与原意相合后再保存。

做第二遍副歌时，先定下要延续的辨识点，再决定这一次要推进什么。可以保留开头的节奏和词，把人物态度交给最后一个词与伴奏应答。也可以保留主唱整句，只让低音或声部层次改变同一句的力度。用「谱面变更」核对两稿真正保留到第几个音，并从同一个句尾听主唱和应答的先后。段落功能可由词、音区、织体等多种因素共同建立。 [de Clercq 的流行摇滚曲式分析](https://mtosmt.org/issues/mto.17.23.3/mto.17.23.3.de_clercq.html) · [Nobile 的主歌、预副歌和副歌研究](https://www.mtosmt.org/issues/mto.22.28.3/mto.22.28.3.nobile.html)

要从上一段借用一句时，先在多轨视图框选完整乐句，用复制预览核对原词和目标拍位。只借动机开头时，可以复制其中几个完整的字，原词留在原句。挪动或清除部分音符前，检查预览列出的缺失与落字变化，再试听这句和相邻的气口。

## 提交前

复核时分别标出歌词句义转折、听到的气口和下一件乐器的入场。它们可能落在不同拍位。谱面留白只提供候选位置。读出那句歌词，核对词义跨拍或跨小节时是否仍连贯，再试听主唱和伴奏是否支持同一个表达意图。 [Pat Pattison 的词曲韵律课程文章](https://online.berklee.edu/takenote/prosody-in-music-and-songwriting/) [Kyle Adams 对说唱乐句、语法与伴奏的分析](https://mtosmt.org/issues/mto.20.26.2/mto.20.26.2.adams.html)

如果句尾接琴声是这次返修的重点，先看两稿的「句尾」听点。相同的琴声可能在长尾版与歌声同时入场，在短尾版留出一小段空隙。试听这个差别，再决定需要连续过渡还是需要留出呼吸。复核显示的是谱面时间，真实的咬字、音色和空间交叠需要听音频。

段落缺少落差时，先对照主唱留白、配器进退和已有的律动。相近的鼓贝斯可能承担连贯性，稀疏的副歌也能制造亲近感。用「段落对照」定位实际变化，再试听同一个功能点，例如两个段首、接唱后的琴声或原声鼓进入的位置。谱面音区重叠只用来定位，有没有抢主唱要结合音色、演奏和混音判断。 [Nobile 的流行歌曲式研究](https://www.mtosmt.org/issues/mto.22.28.3/mto.22.28.3.nobile.html)

核对段落里的演唱时，可用「主唱首字」对照唱入，用「主唱尾音」听最后一次接句。A、B 按各自的速度表取同样长的前后文，遇到段落边界时一起缩短。先看原电平的差异，再匹配响度复听旋律落点、字头和铺底的职责。假如副歌刻意亲密，先试听撤掉一层应答或收窄空间的一版，再决定这处余量要留给主唱还是留给后续段落。

底鼓和贝斯可以一起落下、错开应答，也可以让贝斯延音经过下一记底鼓。「鼓贝斯」把这三种情况放在同一张表。修改前明确这一拍需要重心、弹性还是留白，分别试听节奏组和全混音。微时差的作用随演奏语境变化。 [Senn 等对专业律动微时差的实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC5050221/) [Witek 等的切分研究](https://doi.org/10.1371/journal.pone.0094446)

持音需要返修时，先听字头是否清楚、词义重心在何处、尾音如何接向下句。若考虑颤音，比较原版与晚进、提前收住的一版，同一歌手保留原力度和手绘滑音。时间短时先听一两个周期是否来得及展开。同一句回归时按当时的情绪和接句处理，避免把同一组参数套遍全曲。 [颤音起点的歌手差异](https://www.internationalphoneticassociation.org/icphs-proceedings/ICPhS1999/papers/p14_0981.pdf) [流行歌唱中的颤音与波音](https://pubmed.ncbi.nlm.nih.gov/26700395/)

- 先定下作品设计，做出可试听的核心段。挑一个最能暴露问题的区间，听主唱何处进入、哪句需要换气、伴奏是否抢字或有效接句。可在两个测试副本中制作并渲染同段的两种写法。先明确要听出的区别，比如在同一句落字不变的情况下，试试钢琴提前半拍接句还是等主唱换气再进入。听完再应用选中的一稿。
- 写下决定和具体位置。例如「第 6 拍前撤镲，让长元音进入」「第二次钩子保留头两拍，句尾交给贝斯上行」。有既定素材或范围时先说明保留的内容。
- 先选一处自己认得的钩子，再用「动机」对照另一次出现时的歌词、拍位、和弦与配器。歌词有变化、场景有转折、或主唱需要换气时，可以只动那次回归的末音。在同一回归处 A/B 保持旋律身份和比较条件一致，听新落点是否有表达职责。
- 做同段、近似响度的试听比较，先听主唱与简伴奏，再听鼓贝斯与全混音。从辨词、动机、气口、低部推进和空间层次中找出下一处修改。技术报告单独写峰值、源素材、工程版本和渲染状态。
- 避免用固定四句、抽象套话、强押韵、整轨随机时差或普遍加响度代替作曲。计划里没有证据的听感写成待听审。
- 日语词先核对写法、读音与语气。用「歌词」提取读音并查看每个音符的落点。长音放在要拉住的元音上，弱起与促音安排在适当的短音，试听词义有没有被气口拆开。专名或刻意换读的汉字手动修正。 [VOICEVOX Engine 接口说明](https://github.com/VOICEVOX/voicevox_engine/blob/master/README.md)
- 调声时可以只挑一句里要接起来的两个音。用「滑音」比较在上一音末尾开始过渡，或在下一音起头才向目标靠拢的听感。遇到换气和断句，保留乐句里的休止，再听主唱的重音是否清楚。
