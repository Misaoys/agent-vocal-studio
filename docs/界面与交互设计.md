# Agent Vocal Studio — 界面与交互设计

版本 1.9（应用 0.10.0） · 2026-11-18。界面使用自绘桌面壳、石墨色工作区与本地字体。

## 工作区

```text
┌─────────────────────────────────────────────────────────────────┐
│ 工程列表 · 工程名                    保存 / 导入 / 工程包 / 导出 │
│ 停止 播放 循环 · 时间 / 电平         速度 / 拍号 / 音源 / 撤销  │
├────────────────┬────────────────────────────────────────────────┤
│ 添加轨道       │ 小节与段落                  选区 / 缩放 / 编辑器│
│ 主唱       M S │ ━━━━ 音符 ━━━━━┄┄┄┄                            │
│ 钢琴       M S │ ━━   ━━━━━    ━━━                             │
│ 伴奏       M S │ ┌──波形──┐         ┌─波形─┐                   │
│ 音效       M S │                 ┌波形┐                        │
├────────────────┴─────────── 可拖动分隔条 ───────────────────────┤
│ 钢琴卷帘 / 音频波形 / 批量属性                   参数与增益     │
├─────────────────────────────────────────────────────────────────┤
│ Agent 当前目标                         跟随 / 设计 / 复核 / 知识│
└─────────────────────────────────────────────────────────────────┘
```

编排常驻上半屏，音轨头与时间轴同行。横向滚动固定轨名，纵向滚动固定小节尺。下半屏随选区显示卷帘、单片段波形或多轨批量属性。分隔条支持拖动和方向键。工程清单从左上角图标打开，编排使用窗口全宽。桌面实测见 `多轨工作区实测.png`。

知识、作品设计、曲谱复核采用按需面板。其内容按标题、正文与分隔线组织，不以卡片反复包裹卡片。常驻说明仅保留操作状态；完整帮助放在提示、知识面板与文档中。

## 视觉变量

| 变量 | 取向 |
|---|---|
| 基础背景 | 近黑画布 `#0B0B0C`，黑灰工具条 `#151516`，浮层 `#1C1C1E` |
| 字体 | Inter 与 Noto Sans SC 随应用打包，计时器使用等宽数字 |
| 分隔 | 1 px 细线，不用厚重阴影制造容器 |
| 主文字 | 石墨灰，优先可读性，不用浅灰掩饰信息 |
| 次级文字 | 低一级层级，仍检查正常字号对比度 |

彩色仅用于音轨标记、该轨音符和波形。轨道用饱和色标明身份，播放、导出、选框和 Agent 标记使用中性色。浮层以更亮一级的黑灰与画布区分，时间网格保持低对比。配色取向参考 Apple 的深色模式层级、Radix 的灰阶与点缀色分工，以及 Ableton 的中性主题和轨道着色方式。 [Apple Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode?changes=_6) · [Radix Colors](https://www.radix-ui.com/colors/docs/palette-composition/composing-a-palette) · [Ableton Live Theme & Colors](https://www.ableton.com/en/live-manual/12/first-steps/#theme-colors)
| 强调色 | 蓝色；用于选中、主要动作与 Agent 指示 |
| 辅助色 | 伴奏波形可用低饱和绿色；告警使用克制红色 |
| 字体 | 平台系统字体，工程数值使用等宽数字 |
| 字号 | 主控件 11–13 px；重要编辑数据优先 12–14 px |
| 圆角 | 控件 6–8 px；单一工作面与弹窗 10–14 px |
| 阴影 | 仅弹窗、悬浮提示、必要的浮层 |

布局通过间距、对齐和少量结构分隔建立层级。主工作面不套外框，参数平时直接呈现数值，悬停或编辑时再显示轻反馈。不要为每组文字再创建卡片；不使用大量输入描边或卡套。乐谱网格、选区描边和键盘焦点是功能信息，需要保留。

SVG 图标采用统一 20×20 viewBox、16 px 显示尺寸、1.6 px 描边、圆角端点。只展示有清晰识别含义的图标；需要时配“导入”“歌词”“知识”等短标签。图标按钮提供 tooltip、可访问名称与可见键盘焦点。

## 选区与编辑

- 单击选中音符；空白拖拽框选；Shift 点击增减选区。
- Ctrl+A 选择当前轨音符；Ctrl+C/V 与 Ctrl+D 复用乐句。
- 拖动所选音符移动；拖右边缘调整时值；多音移动保持相对关系。
- ↑/↓ 移调半音，Shift+↑/↓ 移调八度；Del 删除选区。
- 多选时，音高和起点输入以当前音符为锚点整体平移；力度、颤音等共同设置按明确选区应用。
- 选区的调声、落字和修改同步回工程，不只改变画布外观。
- 歌声不允许重叠；复音乐器允许不同音高同时发声。同键重叠、越界或曲线超时值的批次整体回滚，并保留原选区。

Agent 与人共用选区服务。Agent 可以读取人框选的 ID 集合，或按轨道、时间、音高自行选定。范围与基准版本必须一起显示在预览结果中。

## 乐器与表达

添加音轨使用一层菜单：主唱、和声、钢琴、贝斯、鼓组与弦乐。右栏切换类型与真实音色；乐器隐藏歌词和逐音颤音参数。表达区切换力度、踏板、表情、调制、MIDI 音量/声像和效果发送；Alt 拖动擦除控制点，鼓组键盘显示打击名称，贝斯使用低音视区。尾音参数控制全部对齐分轨的共同长度。

## Agent 可视化

SVG 光标浮于画布上，不接管操作系统鼠标。光标小标签只写 Agent；活动条显示当前具体动作，避免重复副标题。目标使用短促蓝色高亮，不用整页闪烁。

跟随开关只影响展示，不影响命令执行。人正在输入、拖拽或使用弹窗时不抢焦点。跨工程操作通过活动条提示，允许用户保留自己的查看位置。

工程更新与光标动画分离：工程提交成功才报告完成。光标未走到目标不能阻塞保存；光标到位也不能作为修改成功的证据。

## 动效配置

所有动效统一从 `web/motion.js` 与 CSS 变量读取，不在各组件随意写不同时间。

| 操作类别 | 进入/反馈 | 退出/完成 | 当前标准时长 |
|---|---|---|---|
| 按钮 | 轻微按压，不弹跳 | 回到原尺度 | 90 / 140 ms |
| 字段变更 | 轻量状态色变化 | 恢复标准底色 | 140 ms |
| 选区与焦点 | 细描边或轻底色 | 淡出高亮 | 160 ms |
| 音轨与工程条目 | 淡入 + 5 px 位移 | 淡出 + 5 px 位移 | 210 / 150 ms |
| 弹窗/面板 | 淡入 + 小尺度位移 | 淡出并退场后关闭 | 230 / 170 ms |
| 提示 | 淡入 | 淡出 | 180 / 140 ms |
| Agent 光标 | 平滑移到目标 | 淡出或留在最近目标 | 520 ms |
| 拖拽与播放游标 | 直接跟随输入/音频时钟 | 结束时保持准确位置 | 不加入延迟性缓动 |

默认曲线：`cubic-bezier(.2,.8,.2,1)`。提供“轻柔/标准/迅捷”和“跟随系统/标准动效/减少动态效果”。减少动态效果时保留必要的状态变化，将运动时长压缩到接近即时，不做持续位移和闪烁。

动效只影响展示，不改音符时间，不作为事务完成信号。移除组件的退出动画使用不可交互的临时展示副本；真实工程与焦点立即按语义更新。

## 状态体系

| 区域 | 需要覆盖的状态 |
|---|---|
| 工程 | 空、载入、已保存、保存中、冲突、缺素材、损坏可恢复 |
| 音符 | 未选、单选、多选、悬停、拖拽、调整时值、编辑拒绝 |
| 伴奏 | 解码、导入、可见波形、缺失、静音、独奏 |
| 歌声 | 引擎离线、可用、排队、渲染、失败、过期试听、完成 |
| Agent | 就绪、定位、读取、编辑、渲染、错误、跟随关闭 |
| 知识 | 主题、风格、来源、作品设计、需要试听的问题 |

常规成功不弹出确认对话框。错误要说明对象和影响，并保留可恢复状态。渲染在底栏显示当前阶段、音轨、细进度和“停止渲染”，通过统一动效进入与退出。请求取消后显示“正在停止”，在工作线程确认前保留忙状态。歌声请求需先返回，最终提交阶段不可取消；刷新后重连既有任务，失败与中断不伪装为完成。

## 联合验收

1. 1440×1000 与 1280×800 均能在一个工作面操作，不产生整页纵向滚动。
2. 缩放和滚动不改变音符时间；标尺、键盘与波形对齐。
3. 所有可见按钮的 SVG、文字、tooltip 和键盘名称一致。
4. 常驻界面没有宣传性标题、重复解释或嵌套卡片。
5. 人框选后 Agent 能读取相同 ID 集合，并仅修改该集合。
6. Agent 聚焦不覆盖正在进行的输入和拖拽。
7. 弹窗进场与退场都可观察；减少动态效果设置生效。
8. 页面无运行时错误，实际播放与导出链路可用。

只有实际执行的检查才写入验证报告；视觉风格是否符合用户偏好仍留给用户检查。


## Windows 菜单与快捷键

标题栏左端打开搜索式命令面板。它和快捷键调用同一批工程命令，支持方向键和回车，输入法组合期间保留文本编辑。文件面板可按常用目录浏览、输入绝对路径、选择多个导入文件或保存导出。

标题栏中部有拖动手柄，双击同一区域可最大化或还原。桌面合成器为普通窗口绘制外部投影。窗口最大化时关闭边缘拖动热区。

`F3` 显示效果器。音轨与总线共用一个平面面板，插入顺序、旁路和参数在同一位置。应用并试听会保存参数并启动该版本渲染。

Agent 指针是发光描边的圆角三角，当前工作留在底栏。准备来自 `agent_focus` 的下一步意图，处理中来自实际 MCP 请求或渲染阶段，完成和失败来自真实回执。渲染显示处理到的音轨和进度。

| 操作 | 快捷键 |
|---|---|
| 新建、导入、保存、另存工程包 | Ctrl+N、Ctrl+O、Ctrl+S、Ctrl+Shift+S |
| 播放、停止、选区循环、跳到开头 | Space、Enter、L、Home |
| 全选、剪切、复制、粘贴、复制乐句 | Ctrl+A、Ctrl+X、Ctrl+C、Ctrl+V、Ctrl+D |
| 撤销、重做 | Ctrl+Z、Ctrl+Shift+Z |
| 移调、跨八度、按网格移动 | ↑ / ↓、Shift+↑ / ↓、Alt+← / → |
| 量化、缩放、还原缩放 | Q、Ctrl++ / Ctrl+-、Ctrl+0 |
| 命令面板、快捷键列表 | Ctrl+K、F1 |

速度面板在一处管理起始速度、速度曲线和拍号变化。速度点、拍号点的应用是一个可撤销操作。面板打开后若工程有新版本，提示重开，保留另一次提交。新增行、删除行、面板与标签切换使用统一动效参数。文件选择、覆盖确认与退出确认也使用同一套动画。

实际桌面截图见 `多轨工作区实测.png`。验证记录包含快捷键、焦点保护、变速播放、循环，以及应用内选择 WAV 和保存工程包。


## 多轨编排

工具栏「编辑器」与 F2 收起或恢复下方细节。编排同时显示小节尺、段落、歌声和乐器的音符，伴奏波形与 MIDI 控制点。点击轨道进入相应细节，双击音符所在的编排位置会将卷帘定位到该拍。键盘编辑按当前操作区选择命令。

工具栏「范围」支持精确拍数和任意音轨组合。「复制」「移动」「清除」先显示影响的音符数和轨数，再提交。总览中 Ctrl+D 打开复制范围，Delete 打开清除范围。Agent 的蓝色边框和光标显示目的地，用户的范围保持独立。

实际画面见 `多轨编排实测.png`。桌面与 MCP 测试覆盖多轨框选、预览、提交、撤销、目标冲突和 Agent 区域聚焦。


## 音频片段

编排区以绿色块区分 WAV，块内显示源窗口的波形。拖动块体移动片段，跨音频轨时迁移到目标轨。Alt 拖动生成副本，拖动左右边缘裁剪。选中后按 S 在游标落点切分，L 循环当前片段，Delete 打开移除预览。双击片段打开属性面板，调整增益、淡入和淡出。切分点在淡化内时，面板提示换一个落点。片段编辑沿用事务、撤销、版本检查和面板进退场动效。

应用内 WAV 选择器可往现有音频轨追加片段，工具栏导入使用独立音频轨。Agent 的光标可通过音轨与拍范围指向片段。

Shift 拖动框选跨轨片段，Ctrl 点击增减。拖动选中项会移动整组，Alt 拖动复制。Ctrl+C 与 Ctrl+V 复制到游标，Ctrl+D 向后复制，Delete 移除，下方可统一调整增益。批量操作保留在一笔事务中，Ctrl+Z 一次撤销。Agent 的白色图标和范围线标示目标，用户的选区与当前编辑轨独立保留。

## 桌面试听

时间旁的双条电平分别显示左右声道峰值。停留在电平上可查看 Windows 输出设备和采样率。播放轨道游标采用原生回调时间，无缓动。音符、多轨选区和音频片段的循环终点统一按源帧处理。停止会回到起点，并取消本次待渲染试听的自动播放。

Agent 试听时，编排和卷帘以浅紫色标出起止位置，活动栏显示本次意图和拍范围。开启跟随时，Agent 光标指向播放或停止按钮。鼠标、键盘和播放控件仍以人的操作为准。
